ESTADO #0

CPU_STATE_NORMAL

Operação padrão do kernel. Ciclos de clock otimizados e sem anomalias detectadas no barramento principal.

Valor: 0 ATIVO
ESTADO #1

AVISO_DE_ESTADO_DA_CPU

Alerta preventivo acionado por carga térmica elevada ou flutuação de tensão nos registradores secundários.

Valor: 1 MONITORANDO
ESTADO #2

CPU_ESTADO_CRÍTICO

Limite de tolerância do núcleo excedido. Necessária intervenção imediata do despachador de tarefas.

Valor: 2 ALERTA MÁXIMO
ESTADO #3

CPU_STATE_EMERGENCY_SHUTDOWN

Desligamento de emergência por falha catastrófica de hardware ou violação de integridade no cofre.

Valor: 3 SEGURANÇA

Como consumir o kisme-sdk em seu projeto

Acesse o repositório público para clonar os cabeçalhos oficiais e vincular a biblioteca estática compilada pelo Maestro Cirurgião.

1

Clone a Vitrine Pública

Baixe os contratos e cabeçalhos oficiais limpos.

2

Vincule a Biblioteca Estática (.a)

Insira a biblioteca comercial gerada no cofre privado.

terminal_integration.sh 
# 1. Clonar a vitrine pública de SDK
git clone https://github.com/carlosandregameplay21-rgb/kisme-sdk.git

# 2. Compilar seu projeto integrando a lib estática
gcc main.c -L./artefatos.o -lquisme -O3 -o meu_app_comercial

# 3. Executar o sistema protegido
./meu_app_comercial
